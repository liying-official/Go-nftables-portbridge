# 交互式一键安装 — v2.5.0

[English](ONECLICK.en-US.md) | 简体中文

使用 `scripts/install-oneclick.sh`，支持 Debian/Ubuntu、amd64/arm64。脚本自行下载 GitHub 最新稳定 Release 的对应架构和语言预编译包，不需要 Go 编译器。首次运行前，请从可信来源取得并审阅脚本；不要修改或解压后覆盖已签名发布包中的文件。

```bash
sudo bash scripts/install-oneclick.sh
```

必须在交互终端运行。选择语言前只显示英文提示：`1` 为英语，`2` 为简体中文；后续提示按所选语言显示。上面的路径指包含本脚本的源码检出；脚本本身也可单独复制后用 Bash 运行。

所选语言包决定 WebUI 的初始语言。每个包都包含简体中文和 English，可通过界面的语言菜单切换，无需重新安装。

## 安装流程

1. 选择语言，自动识别系统与架构。
2. 准备依赖，输入一个或多个客户端白名单 IP/CIDR（逗号或空格分隔）。不能为空，不接受 `/0`、多播、带 zone 的地址或 IPv4 映射 IPv6。
3. 输入 HTTPS 管理端口，默认 `9080`；占用时要求重新选择。
4. 下载最新稳定预编译包，依次校验顶层 Ed25519 签名、归档摘要、包内签名清单及源码/脚本/二进制摘要。固定信任公钥不从未知下载源动态替换；发布者换钥时需要更新脚本，不会绕过验证。
5. 确认后以 `--no-start` 安装，生成十年自签证书。启动前写入持久严格白名单，关闭自动 LAN 识别及明文 HTTP，再启动服务。
6. 检查稳定运行、HTTPS 证书信任、管理员鉴权及实际白名单，成功后显示证书 SHA-256、各可用网卡 IP 的管理 URL 和管理员令牌。

管理监听为 `0.0.0.0`，系统支持 IPv6 时同时监听 `::`，并通过严格白名单限制来源；回环恢复通道仍可用。这不同于原始安装器默认的仅回环监听。白名单限制的是管理页面/API，不是转发端口。脚本不修改主机防火墙、云安全组或 NAT，输出地址也不是自动探测的公网地址。IPv6 URL 使用方括号；输出的管理地址排除回环、链路本地、未就绪及已弃用地址。

自签证书不被浏览器自动信任。先经可信渠道核对指纹，再建立客户端信任。以后可在管理设置中配置有效证书路径并重启；网卡/IP 改变后也需核对证书 SAN。请勿录屏、公开截图或保存包含管理员令牌的终端输出。

## 已有实例与失败处理

本脚本只负责首次安装。发现既有配置、TLS 目录、程序或服务时拒绝覆盖，也不自动升级；已有实例按 README 的升级流程操作。失败不执行破坏性回滚，可能保留已安装文件；请检查提示中的私有诊断日志及服务状态，不要直接删除归属/恢复记录。

## 最小化检查

```bash
bash scripts/install-oneclick.sh --check
```

仍会选择语言、输入白名单和空闲端口，真实下载并验证最新 Release，输出计划 URL，但不安装依赖、不修改服务/配置、不读取已有管理员令牌。需要已安装 curl、Python 3、OpenSSH ssh-keygen、iproute2、tar/gzip 和 coreutils。适用于已有实例的非覆盖验证。
