Web 访问控制

只按直接连接来源 IP 判断，不信任代理请求头。

安装和升级后强制 HTTPS；未提供证书时会自动生成有效期 10 年的自签证书。默认只监听 127.0.0.1/::1，远程访问仍需配置监听地址与白名单。

严格模式只允许回环地址和下方手动白名单，忽略自动 LAN 与启动参数临时授权，并强制原生 TLS。必须先配置证书、重启并通过 HTTPS 登录，再启用此选项；同时在主机防火墙设置相同来源 IP。

自定义 DNS 使用普通 UDP/TCP DNS，请只填写可信本地解析器；需要加密 DNS 时在系统侧部署受信 DoT/DoH stub，再填写其本地地址。

替换正式证书：将证书和私钥放到服务器，填写上方绝对路径、保存并重启服务；同路径续期也需重启。这里显示的是当前进程实际加载的证书。TLS 最低版本默认 1.2，可选 1.3；私钥可用 portbridge 属主 0600 或 root:portbridge 0640，目录须允许服务账户读取。

新增规则

nftables 优先：外部同族流量使用内核 flowtable 快速路径，本机 output 使用 nftables NAT，跨族及回环 fallback 走 Go；GO：整条规则强制使用 Go 代理。

端口段必须等长，例如 10000–10099 → 20000–20099；最多 4096 个端口。

域名每次刷新都会重新校验全部 A/AAAA 结果，防止 DNS 重绑定。未明确授权时拒绝回环、私网、链路本地、CGNAT、组播与云元数据地址。

Go UDP 性能参数

仅作用于 Go UDP 数据面。Worker 是整条规则共享的预算（端口段/双栈会自动分摊），0 表示按 GOMAXPROCS 自动选择；每个监听 socket 至少 1 个。默认 batch 64、单包缓冲 2048B。
